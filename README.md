Exports your [*MkDocs*](https://github.com/mkdocs/mkdocs), [*ProperDocs*](https://github.com/ProperDocs/properdocs) and [*Zensical*](https://zensical.org/) documentation to PDF: a document for each page, and books combining pages into a single document.

- [Documentation](https://adrienbrignon.github.io/mkdocs-exporter)
- [PyPI](https://pypi.org/project/mkdocs-exporter)
- [Examples](https://adrienbrignon.github.io/mkdocs-exporter/examples/)

## Features

- 📚 **Books** - combine pages into PDF documents with bookmarks, a table of contents and working links
- 🎨 **Customizable** - full control over the resulting documents
  - [Cover pages](https://adrienbrignon.github.io/mkdocs-exporter/guide/cover-pages/) written as Jinja templates
  - [Headers and footers](https://adrienbrignon.github.io/mkdocs-exporter/guide/headers-and-footers/) with page numbers
  - Custom [stylesheets, scripts and hooks](https://adrienbrignon.github.io/mkdocs-exporter/guide/styles-and-scripts/)
  - Per-page options in the [front matter](https://adrienbrignon.github.io/mkdocs-exporter/reference/front-matter/)
  - [Buttons](https://adrienbrignon.github.io/mkdocs-exporter/guide/buttons/) at the top of your pages (e.g. to download the page or the book as PDF)
  - Dedicated support for the [`material`](https://github.com/squidfunk/mkdocs-material) and [`readthedocs`](https://www.mkdocs.org/user-guide/choosing-your-theme/#readthedocs) themes, check out [sample PDF documents](https://adrienbrignon.github.io/mkdocs-exporter/examples/#themes)
- ♿ **Accessible** - documents are tagged for screen readers, with bookmarks, their language and document information
- 🚀 **Fast** - documents are rendered concurrently, and unchanged ones are reused from a cache
- ⭐ **Powerful** - documents are printed by Chromium, driven by [*Playwright*](https://github.com/microsoft/playwright-python), with [CSS Paged Media](https://www.w3.org/TR/css-page-3/) support

## Supported tools

| Tool | Support |
|---|---|
| MkDocs `>= 1.6, < 2` | ✅ A plugin, documents are generated while building the website |
| [ProperDocs](https://github.com/ProperDocs/properdocs) | ✅ The same plugin |
| [Zensical](https://zensical.org/) | 🧪 A command, run once the website is built (experimental, see the [Zensical guide](https://adrienbrignon.github.io/mkdocs-exporter/how-to/zensical/)) |
| MkDocs 2.0 | ⏳ Not yet (it doesn't support plugins) |

Requires Python `>= 3.11.5`.

## Installation

The package is hosted on [*PyPI*](https://pypi.org/project/mkdocs-exporter/) and can be installed via `pip` (or your favourite package manager), along with the browser it uses:

```bash
pip install "mkdocs-exporter>=7.0.0rc1"
playwright install --with-deps --only-shell chromium
```

Version 7 is a release candidate: until 7.0.0 is released, `pip install mkdocs-exporter` (without a version) installs 6.2.0.

Upgrading from v6? Read the [migration guide](https://adrienbrignon.github.io/mkdocs-exporter/how-to/migrating-to-v7/).

## Usage

The following configuration (adapted from the [`mkdocs.yml`](https://github.com/adrienbrignon/mkdocs-exporter/blob/master/mkdocs.yml) file used by this documentation) covers the main features:

```yaml
plugins:
  - exporter:
      formats:
        pdf:
          enabled: !ENV [MKDOCS_EXPORTER_PDF, true]
          concurrency: 8
          stylesheets:
            - resources/stylesheets/pdf.css
          covers:
            front: resources/templates/covers/front.html.j2
            back: resources/templates/covers/back.html.j2
          footer:
            right: "Page {page} of {pages}"
          books:
            - output: documentation.pdf
              covers: front
              toc:
                enabled: true
```

With MkDocs and ProperDocs, documents are generated by `mkdocs build` (or `properdocs build`).
Zensical doesn't run plugins: it ignores this configuration (also accepted as `[project.plugins.exporter]` in `zensical.toml`), which the `mkdocs-exporter` command reads to export the website once it is built:

```bash
zensical build
mkdocs-exporter build
```

Check out the [examples](https://adrienbrignon.github.io/mkdocs-exporter/examples/): documents generated from a small website (with cover pages, tables of contents, headers and footers...), with their configuration ([`examples/`](https://github.com/adrienbrignon/mkdocs-exporter/tree/master/examples)).
