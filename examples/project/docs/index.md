# Welcome

This small website shows the documents generated by [MkDocs Exporter](https://github.com/adrienbrignon/mkdocs-exporter): every page has a PDF document of its own, and all pages are combined into a single document, with a table of contents and bookmarks.

!!! tip "Download"

    The documents are generated along with the website: the PDF document of each page sits next to its HTML file, and the combined document at the root of the website.

## What's inside

| Page | Contents |
|---|---|
| [Writing pages](guide/writing.md) | Text, lists, code, admonitions, tabs and footnotes |
| [Printing pages](guide/printing.md) | Page sizes, headers and footers, cover pages |

## How it works

Pages are printed by a headless browser, using its support of CSS Paged Media: page sizes, margins, headers and footers, named pages.
Styles of the website apply, along with stylesheets meant for documents only.
